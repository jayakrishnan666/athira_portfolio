# Athira B Digital Marketing Portfolio

Open index.html directly for an offline preview. Keep index.html, styles.css, app.js and the assets folder together.

For deployment, extract the ZIP and upload its contents to the root of any static web host. The publish directory is the folder containing index.html. Leave the build command empty. Relative paths also support deployment under a subdirectory.

To edit copy, campaign results or contact information, update index.html in a text editor. Update styles.css to change the design and replace images in assets as needed. The portfolio has no database, server, package installation or external dependencies.
